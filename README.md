# «Вы не одна» — приложение Кризисного центра для женщин г. Вологда

Android-приложение (Kotlin + Jetpack Compose) в фирменном стиле kriziscentr.ru.

## Что внутри

- **Главная** — «Позвонить 112» и «Горячая линия 24/7» в одно касание, плитки разделов, советы «Если опасность рядом».
- **Что делать** — 10 пошаговых инструкций с сайта центра (побои, физическое и сексуализированное насилие, медпомощь, угрозы, убежище, бездействие полиции, преследование, интернет-преследование, шантаж). Внутри инструкций — карточки нужных учреждений.
- **Куда идти** — учреждения Вологды с фильтром по ситуации, звонком и маршрутом в картах.
- **Телефоны** — экстренные, центра, всероссийские и вологодские линии.
- **Безопасность** — SOS-SMS до 3 доверенных контактов с геолокацией, тревожный чемоданчик (чек-лист), план безопасности.
- **О центре** — услуги, контакты, соцсети, реквизиты для пожертвований.
- Кнопка **«Выход»** на каждом экране: мгновенно показывает рабочий стол и убирает приложение из недавних.

Все данные пользователя (контакты, отметки) хранятся только на телефоне; резервное копирование отключено.

## Как менять контент

Все тексты, адреса и телефоны — в одном файле:
`app/src/main/java/ru/kriziscentr/vologda/data/Content.kt`.

## Сборка

Откройте папку в Android Studio и нажмите Run, либо из командной строки:

```
gradlew assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`.

Сейчас релиз подписан отладочным ключом — для установки «из файла» этого достаточно.
Для публикации в RuStore / Google Play нужно создать собственный ключ подписи
и указать его в `app/build.gradle.kts` (`signingConfig`).
